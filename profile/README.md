# Soulstack

**Calm software. Serious delivery.**

Soulstack is an independent British software house building creator tools, games, desktop apps, booking systems, and open-source AI tooling.

## Products

| | |
|---|---|
| [Soulstack.gg](https://soulstack.gg/) | Creator tools for Twitch, Discord and OBS |
| [Creator Console](https://creator.soulstack.gg/) | Creator app |
| [Documentation](https://docs.soulstack.gg/) | Product docs |

| | |
|---|---|
